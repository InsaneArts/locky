# Locky 0.1.0

The first public release. Locky is a lock screen for your Mac that you build yourself: themes and widgets are Lua files, drawn with SwiftUI and Metal. It unlocks with Touch ID or your login password.

- 43 themes, some with live wallpapers drawn in Metal.
- Customize: drag widgets on the live lock screen, add any of the 27 widgets, and change the background, the colors, and the font.
- Lock Now, a shortcut, Lock Automatically, and Lock with the Touch ID button.
- Plugins from git, and a skill for coding agents that write themes and widgets.
- Locky checks for updates once a day and asks before it installs one.
